# Core Pack license receipts

Add one notice or receipt for every package or independently licensed asset.
The matching `manifest.json` entry must point to that file and record:

- SPDX/license id when available;
- copyright/author;
- redistribution permission;
- commercial-output permission;
- attribution or notice requirement;
- source URL and version;
- trademark restrictions when applicable.

An empty directory means the Core Pack contains no admitted third-party
content.
